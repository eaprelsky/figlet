# Figlet

Приложение для нелинейного чтения: автор → книга → глава → раздел → смысловой фрагмент → абзац. Автор — верхний уровень. Пересказ помогает выбрать, куда углубиться, оригинал остаётся источником истины.

Основной способ управления — семантический zoom. Кнопка «+» уменьшает исходный диапазон текста, суммируемый в одну страницу. Кнопка «−» увеличивает диапазон и возвращает более общий обзор; из книги она ведёт к автору. Положение в исходнике сохраняется отдельным якорем, поэтому «−», затем «+» возвращает к прежнему фрагменту. Стрелки сохраняют масштаб и переходят к соседней странице на этом уровне. На уровне книг они переходят между произведениями автора; на уровне глав — между главами всей книги. Оригинал дополнительно разбит на страницы по шесть абзацев.

Интерфейс не строится вокруг диалога: начальный экран содержит авторов и библиотеку, главный экран — карту произведений или разделов. Поиск открывается в отдельном окне. Вопрос по тексту — второстепенный инструмент в отдельном окне или через выбор абзаца. Развёрнутые комментарии скрыты в деталях, чтобы карта оставалась основной поверхностью чтения.

## Первая версия

- Поиск в открытых библиотеках; AI-навигация по автору и рекомендация произведений.
- Загрузка по URL или файлом: TXT, Markdown, HTML, FB2, EPUB, PDF с текстовым слоем.
- Дерево с хлебными крошками, соседними разделами и историей браузера.
- Ленивые разборы: смысл, вклад, важность, что можно пропустить и карта дочерних фрагментов.
- Вопрос по разделу или выделенному абзацу; цитаты — только из извлечённого оригинала.
- Библиотека, тексты, позиция, разборы и ответы в IndexedDB; тема и модель в cookie.
- Личный DeepSeek API key только в памяти вкладки / sessionStorage по явному выбору. Опционально общий серверный ключ через окружение.
- Светлая, тёмная и системная темы; мобильный интерфейс; экспорт и импорт личной библиотеки.

## Границы достоверности

Рекомендации до загрузки книги — общая ориентировка модели. Разбор и ответы после загрузки привязаны к переданному фрагменту. Оценка важности субъективна. Неполный или обрезанный текст явно отмечается. Нет обхода платного доступа. Сканы PDF требуют OCR вне приложения. Файлы и ключи не сохраняются на сервере.

## Визуальное решение

Цвета: бумага #f7f8fa, поверхность #ffffff, чернила #222632, вторичный текст #717887, индиго #4355b9, линия #e3e6ee. Тёмная тема — глубокий синий фон #171c29 и светлые чернила #e7eaf2.

Текст книги — Literata, интерфейс — Golos Text, шрифты хранятся локально. Заголовки по левому краю. Широкое поле вокруг узкой колонки чтения. Библиотека слева, карта текущего уровня в центре. На телефоне библиотека открывается отдельным слоем.

```text
figlet        Библиотека                       тема / настройки
              Что хотите понять?
Мои книги     [ автор, книга или вопрос                 ]
  книга       Маршруты чтения / ваши книги

Библиотека    Книга › Глава › Фрагмент
  книга       Название текущего уровня
  книга       [Суть] [Оригинал]       важность
              Краткий разбор
              Дочерний фрагмент                  глубже
              Дочерний фрагмент                  глубже
              [ Вопрос по этому фрагменту              ]
              предыдущий       выше            следующий
```

Главный визуальный приём — уменьшающийся масштаб оглавления и постоянно видимый путь к источнику. Декоративные карточки, обложки и чат-пузыри не нужны. При проверке концепции оставлены обычные названия действий и один акцент: это инструмент чтения, а не рекламный лендинг.
